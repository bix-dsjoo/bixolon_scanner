# Camera Crop 2048

Windows USB 카메라의 중앙 **2048×2048** 영역을 실시간 표시하고 PNG로 저장하는 독립 유틸리티입니다.
Scanner / Scanner Lite와 별도 설치되며 Worker·모델·추론 기능을 포함하지 않습니다.
유틸리티 버전은 `1.0.0`이며 Scanner 제품 버전과 무관합니다.

## 설치와 사용

`CameraCrop2048-1.0.0-Setup.exe`를 실행합니다. Python 설치나 관리자 권한이 필요 없습니다.
설치 후 시작 메뉴 또는 바탕 화면의 `Camera Crop 2048`을 실행하세요.

- 기본 입력: 카메라 번호 `0`, `3264×2448` MJPEG 요청.
- 현재 ZHWY Camera 기준 중앙 좌표: `(608, 200)`부터 `2048×2048`.
- 미리보기는 정사각형 전체를 창에 맞추고 비율을 유지합니다.
- **Space / 크롭 PNG 촬영**: 현재 보이는 크롭을 정확히 2048×2048 PNG로 저장합니다.
- 저장 위치: 사용자 홈의 `Pictures/CameraCrop2048`. 앱에서 폴더를 바꿀 수 있습니다.
- **F11**: 전체 화면, **Esc**: 전체 화면 종료.
- **연결 해제 / 연결**: 카메라를 전환하거나 오류 후 다시 연결합니다.
- 원본의 어느 변이든 2048px 미만이면 오류를 표시하고 촬영을 막습니다. 확대·여백 추가로 대체하지 않습니다.
- 크롭은 좌우 반전·원근 보정·렌즈 보정을 하지 않습니다.
- 다른 카메라 프로그램이 장치를 사용하면 연결하지 못할 수 있습니다. 해당 프로그램을 닫은 후 다시 연결하세요.
- 이미지 자동 저장, 외부 전송, 자동 삭제는 없습니다. 촬영 사진은 사용자가 저장 폴더에서 관리합니다.
- 앱 제거는 Windows 설치된 앱에서 할 수 있으며 사용자가 저장한 사진은 삭제하지 않습니다.

이 설치 프로그램은 코드 서명되지 않았습니다. SHA-256은 파일 변경 여부 확인용이며 발행자 인증은 아닙니다.

## 개발 실행과 빌드

Python 3.11 x64, requirements.txt 의존성과 Inno Setup 6을 사용합니다.

```powershell
python -m bixolon_scanner.operations.camera_crop
./tools/camera_crop_2048/build.ps1
```

빌드 결과는 `artifacts/camera-crop-2048/1.0.0/build-날짜시간`에 생성됩니다.
폴더형 실행 파일과 DLL, Python/Tcl/Tk, 라이선스, 파일별 SHA-256 manifest, Setup과 Setup SHA-256을 포함합니다.
패키징 시 실제 EXE를 실행해 Tk 초기화·중앙 크롭·PNG 픽셀 보존을 검사합니다.
명시적 개발 진단 `--verify-package <폴더> --live-camera`는 실제 카메라의 크롭 이미지와 결과 JSON을
해당 폴더에 저장합니다. 진단 파일은 자동 삭제하지 않으며 테스트 후 폴더에서 직접 정리할 수 있습니다.
