# 0.2.1 변경점

0.2.0의 D-FINE640·DINOv3 모델과 Catalog를 유지한다. 검출 점수 0.025 이상 후보는
이웃 마스크 context로 보존하고 0.04 이상 출력 ROI만 분류한다. 불필요한 조각·중복의
분류 연산과 출력을 줄이면서 남은 ROI의 상태·품목 순위가 바뀌지 않도록 검증한다.
실제 객체와 GT, 최종 상태 정책을 유지하며 오류를 재촬영으로 바꾸지 않는다.

공개 API·상태·reason code와 N100 CPU→GPU→CPU 처리 및 CPU fallback은 동일하다.
제품 버전은 0.2.1, Flutter 내부 build는 24다.

[N100 실행·측정](../experiments/n100-0.2.1.md)을 참조한다.
