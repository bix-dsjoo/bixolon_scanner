# BIXOLON Bakery AI Scanner 0.2.0

학습 미사용 로그132장에서 객체 승인95%, 오승인·미검출0, HTTP p95 200ms를 목표로 개발했습니다.
소스 CUDA3회는1,078/1,096 승인·오승인0·미검출0·p95 84~85ms였습니다. CPU 속도는 미달이며
N100 내장 Intel UHD의 실제 성능은 미측정입니다. 로그는 이번 전역 정책 선택에 사용했습니다.

| 구성 | 0.1.18 | 0.2.0 |
|---|---|---|
| 검출 | SSDLite320 | D-FINE HGNetV2-S640, class-agnostic |
| 분류 | ConvNeXt-Tiny192/224 | 같은 학습 가중치·Catalog |
| Frozen 검증 | 경계 후보 ViT-B/16160와 회전 합의 | 유지, N100 프로필에서 ViT는CPU |

프레임 전체 hard 품질 조기 종료와 ERROR계약은 유지합니다. 검출 score는물체 후보를 찾는
점수이며 품목 승인의 근거로 사용하지 않습니다. 기존에이미 분류된 포함 중복은UNKNOWN으로
유지합니다. 선택적 low-score 분류 생략 후보는 판정은같았지만속도개선이없어 활성화하지않았습니다.

CPU+Intel GPU 프로필은CPU검출2threads, GPU primary/detail, CPU verifier4threads입니다.
GPU가시작하지못하면CPU로초기화합니다. 실행중GPU장애 요청은ERROR이며 다음요청부터CPU로
전환합니다. readiness와구조화로그에서실제provider를확인합니다. N100실측없이속도를보장하지않습니다.

학습·비교·세부미달사항은[N100개발진단](../experiments/n100-0.2.0.md)에 기록합니다.
