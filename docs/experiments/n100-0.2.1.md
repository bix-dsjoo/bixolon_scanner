# N100 0.2.1 최종 실행·실측

최종 선택은 **RepViT GPU R4**다. Intel N100 / Intel UHD, Windows10 19044,
드라이버32.0.101.6299에서132장×3회를 측정했다. ORT-OpenVINO1.24.1 / OpenVINO2025.4.1,
CPU detector4스레드 → GPU FP16 primary/detail → CPU 독립 verifier다.
동일 검증 입력 재사용·선택적 병렬 검증과 명시적 CPU fallback을 사용한다.
GPU 실행 장애를 재촬영으로 바꾸지 않으며 실제 fallback의 전환/오류 의미는 유지한다.

| 구성 | HTTP p50/p95/p99/최대 ms | 1초 이내 |
|---|---:|---:|
| DINO 기준 | 765.9 / 940.9 / 1146.3 / 1203.8 | 386/396 |
| 최종 RepViT GPU | 493.3 / 732.4 / 799.1 / 949.8 | 396/396 |
| RepViT CPU | 517.8 / 798.7 / 991.3 / 1161.1 | 392/396 |

각 반복은 GT1096개 중 정답승인1085, 오승인0·미검출0, APPROVED1085/UNKNOWN9/
SEGMENT_RECAPTURE18, 추가검출16이다. GPU와CPU의396쌍 판정 차이는0이다.
워밍업10회 후 단일 요청을 순차 실행했다. 준비시간22.8초와 카메라/UI는 위 지연에 포함하지 않았다.
41번 이미지의 최대949.8ms로 여유가50.2ms이며 CPU는41번3회·68번1회가1초를 초과했다.
추가 검출과 개별 승인손실2개가 남고, 별도 final300 기존 오승인4개와 독립 validation 부재도 유지한다.
일반화 성능·장시간SLA·모든 장면의1초보장으로 표현하지 않는다. 0.2.0 비교는 제외했다.

최종 배포 폴더: `artifacts/distributions/0.2.1-final-n100`.
N100 Lite Setup은 기존 Lite 설치본을 업데이트한다. 실험 EXE만 실행한 경우에도
설치된 앱은 자동으로 교체되지 않으므로 최종 Setup을 실행해야 한다.
독립 Worker ZIP은 압축을 풀어 `RUN-N100-WORKER.cmd`를 실행한다. 기본 포트8000,
첫 인수로 다른 포트를 지정할 수 있다. PowerShell/Python 설치는 필요 없다.
기존 앱·실험 Worker를 종료한 후 실행하고 결과·사용자 로그는 유지한다.

최종 선택에 사용한 원자료는 버전 설정의 evaluation_evidence로 해시 고정했다.
자세한 분석·실패 영역은 배포물의 `Reports`에 제공한다.
Checksum은 손상·변경 탐지이며 발행자 진위 인증은 제공하지 않는다.
