BIXOLON Bakery AI Scanner 0.1.12 - Windows OpenVINO Worker ZIP
================================================

실행 방법
1. ZIP 전체를 같은 폴더에 압축 해제합니다.
2. RUN-BIXOLON-WORKER.cmd를 실행합니다.
3. Worker 주소는 http://127.0.0.1:8000 이고 endpoint는 POST /v1/scan 입니다.
4. 종료하려면 Worker 창에서 Ctrl+C를 누릅니다.

실행 구성
- class-aware SSDLite320 Detector: OpenVINOExecutionProvider CPU
- 주 Embedder, 180도 Embedder, 독립 Verifier: OpenVINOExecutionProvider Intel GPU
- count verifier와 object_presence verifier는 구성하지 않음
- Intel GPU graph를 초기화할 수 없으면 경고를 남기고 classifier를 CPU로 재시작
- fallback 후 /health/ready의 provider는 openvino
- Python, Flutter, CUDA 별도 설치 불필요
- 사용자별 version 디렉터리의 OpenVINO 컴파일 캐시 사용

필수 조건
- Windows 10 1809 이상, x64
- Intel GPU 가속 사용 시 활성화된 Intel UHD Graphics와 최신 Intel Graphics Driver
- Microsoft Visual C++ 2015-2022 x64 Runtime

무결성
- ZIP 옆의 .sha256 파일로 ZIP을 검증할 수 있습니다.
- worker-manifest.json에는 ZIP 내부 파일별 SHA-256이 기록됩니다.
- hardware-reference-result.json은 동일 모델·정책의 N100 참조 측정 원문입니다.
- deployment-provenance.json은 Runtime·Catalog와 측정 원문의 SHA-256을 기록합니다.

제한
- Intel N100 v41 100장 측정에서 GPU classifier 구성 평균/p95는 336.946/488.413ms,
  semantic mismatch와 ERROR는 0건이었습니다.
- v42 선택 ROI Worker 변경의 N100 추가 효과는 직접 측정하지 않았습니다.
- 장비 한 대의 참조 결과이며 SLA 또는 인증이 아닙니다.
- 배포 파일에는 Authenticode 서명이 없습니다.
