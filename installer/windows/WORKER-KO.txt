BIXOLON Bakery AI Scanner 0.1.16 - Windows CPU Worker ZIP
===============================================

실행 방법
1. ZIP 전체를 같은 폴더에 압축 해제합니다.
2. RUN-BIXOLON-WORKER.cmd를 실행합니다.
3. Worker 주소는 http://127.0.0.1:8000 이고 endpoint는 POST /v1/scan 입니다.
4. 종료하려면 Worker 창에서 Ctrl+C를 누릅니다.

실행 구성
- Detector, 192 primary, 선택 224 detail path와 선택 ViT verifier: ONNX Runtime CPU
- Python, Flutter, CUDA, OpenVINO 별도 설치 불필요

필수 조건
- Windows 10 1809 이상, x64
- Microsoft Visual C++ 2015-2022 x64 Runtime

무결성
- ZIP 옆의 .sha256 파일로 ZIP을 검증할 수 있습니다.
- worker-manifest.json에는 ZIP 내부 파일별 SHA-256이 기록됩니다.
- deployment-provenance.json은 Runtime·Catalog, 실행 provider와 패키징 변환을 기록합니다.

제한
- 지연값은 측정 장비와 입력에 종속되며 SLA 또는 인증이 아닙니다.
- 배포 파일에는 Authenticode 서명이 없습니다.
