BIXOLON Bakery AI Scanner 0.1.18 - Windows CPU 설치 안내
=================================================

지원 환경
- 64비트 Windows 10 1809 이상 또는 Windows 11
- x64 CPU, 메모리 4GB 이상; 8GB 권장
- 카메라 또는 JPEG/PNG 이미지
- Python, Flutter, CUDA, OpenVINO 별도 설치 불필요

실행
1. 시작 메뉴 또는 바탕 화면의 "BIXOLON Bakery AI Scanner"를 실행합니다.
2. 처음 실행하면 Runtime/Catalog checksum 검증과 모델 warm-up 때문에 준비 시간이 걸릴 수 있습니다.
3. 앱이 준비되면 카메라로 촬영하거나 이미지 파일을 선택합니다.

Windows 기본 실행 구성
- 1-class SSDLite320 Detector: ONNX Runtime CPU, 1 worker x 8 threads
- 주 192 Embedder, 선택 224 detail path, 선택 ViT verifier: ONNX Runtime CPU, 각 12 threads
- Worker 주소 http://127.0.0.1:8000

진단 범위와 주의
- 이 CPU 설치본은 Intel/NVIDIA GPU 유무와 무관하게 실행되는 KIOSK/POS 호환 배포물입니다.
- 개발 진단과 최종 300장 HTTP 검증값은 배포 증빙 문서를 확인하십시오. 측정 PC의 값이며 SLA가 아닙니다.
- 고성능 앱 번들은 동일 ONNX와 판정 정책을 사용하는 CUDA 배포물로 별도 제공됩니다.
- ERROR는 촬영 재시도 판정이 아니라 입력, 구성, 모델 또는 시스템 오류입니다.
- 설치 파일은 SHA-256으로 전송 중 손상을 확인하지만 Authenticode 서명은 없습니다. Windows가
  알 수 없는 게시자 경고를 표시할 수 있으므로 전달받은 Setup EXE의 SHA-256을 먼저 확인하십시오.

제거
- Windows 설정 > 앱 > 설치된 앱 > BIXOLON Bakery AI Scanner에서 제거합니다.
- 제거해도 작업자가 저장한 스캔 기록과 원본 이미지는 자동 삭제하지 않습니다.

버전
- 제품, 앱 표시, Worker, Runtime, Catalog: 0.1.18
- Flutter 내부 build: 0.1.18+21
