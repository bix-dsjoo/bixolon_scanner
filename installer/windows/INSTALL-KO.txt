BIXOLON Bakery AI Scanner 0.1.12 - Windows OpenVINO 설치 안내
=====================================================

지원 환경
- 64비트 Windows 10 1809 이상 또는 Windows 11
- x64 CPU, 메모리 4GB 이상; 8GB 권장
- Intel GPU 가속 사용 시 Intel UHD Graphics와 최신 Intel Graphics Driver
- 카메라 또는 JPEG/PNG 이미지
- Python, Flutter, CUDA 별도 설치 불필요

실행
1. 시작 메뉴 또는 바탕 화면의 "BIXOLON Bakery AI Scanner"를 실행합니다.
2. 처음 실행하면 모델 checksum 검증과 warm-up 때문에 준비 시간이 걸릴 수 있습니다. 다음 실행부터는
   사용자별 OpenVINO 컴파일 캐시가 준비 시간을 줄입니다.
3. 앱이 준비되면 카메라로 촬영하거나 이미지 파일을 선택합니다.

Windows 기본 실행 구성
- class-aware SSDLite320 Detector: OpenVINOExecutionProvider CPU, 1 worker x 4 threads
- 주 Embedder, 180도 Embedder, 독립 Verifier: OpenVINOExecutionProvider Intel GPU
- count verifier와 object_presence verifier는 구성하지 않음
- Intel GPU 초기화 실패 시 경고 로그를 남기고 classifier를 CPU로 명시적으로 fallback
- Worker 주소 http://127.0.0.1:8000

진단 범위와 주의
- 같은 모델·정책 v41의 Intel N100 100장 실측에서 GPU classifier 구성의 client 평균/p95는
  336.946/488.413ms, CPU-only는 418.587/681.696ms였습니다.
- 최종 상태, bbox, class rank 불일치와 ERROR는 0건이었습니다.
- confidence 최대 차이는 0.0137197375로 provider 허용치 0.02 안이며 bit-exact 결과는 아닙니다.
- v42 선택 ROI Worker 변경은 개발 PC 전수에서 검증했지만 실제 N100 추가 효과는 직접 측정하지
  않았습니다. 위 결과는 장비 한 대의 참조 진단이며 지연시간 또는 SLA를 보장하지 않습니다.
- fallback 사용 여부는 /health/ready의 provider로 확인합니다. GPU 사용 시
  openvino+openvino_gpu, CPU fallback 시 openvino입니다.
- ERROR는 촬영 재시도 판정이 아니라 입력, 구성, 모델 또는 시스템 오류입니다.
- 설치 파일은 SHA-256으로 전송 중 손상을 확인하지만 Authenticode 서명은 없습니다. Windows가
  알 수 없는 게시자 경고를 표시할 수 있으므로 전달받은 Setup EXE의 SHA-256을 먼저 확인하십시오.

제거
- Windows 설정 > 앱 > 설치된 앱 > BIXOLON Bakery AI Scanner에서 제거합니다.
- 제거해도 작업자가 저장한 스캔 기록과 원본 이미지는 자동 삭제하지 않습니다.
- 기록은 현재 Windows 사용자 Application Support 아래 ProductScanner 폴더에 남습니다.
