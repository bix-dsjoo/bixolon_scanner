BIXOLON Scanner 0.1.4 - N100 Hybrid OpenVINO 설치 안내
=====================================================

지원 환경
- 64비트 Windows 10 1809 이상 또는 Windows 11
- Intel Processor N100 권장, 메모리 8GB 이상 권장
- Intel UHD Graphics와 최신 Intel Graphics Driver
- 카메라 또는 JPEG/PNG 이미지
- Python, Flutter, CUDA 별도 설치 불필요

실행
1. 시작 메뉴 또는 바탕 화면의 "BIXOLON Scanner"를 실행합니다.
2. 처음 실행하면 모델 checksum 검증과 warm-up 때문에 준비 시간이 걸릴 수 있습니다. 다음 실행부터는
   사용자별 OpenVINO 컴파일 캐시가 준비 시간을 줄입니다.
3. 앱이 준비되면 카메라로 촬영하거나 이미지 파일을 선택합니다.

N100 기본 실행 구성
- Detector: OpenVINOExecutionProvider CPU, 1 worker x 4 threads
- 주 Embedder, 180도 Embedder, 독립 Verifier: OpenVINOExecutionProvider Intel GPU
- Intel GPU 초기화 실패 시 경고 로그를 남기고 CPU Embedder로 명시적으로 fallback
- Worker 주소 http://127.0.0.1:8000

주의
- 동일 모델·Catalog의 0.1.4 N100 100장 참조 측정에서 GPU Embedder는 CPU-only보다 평균 1.313배,
  p95 1.288배 빨랐습니다.
- 같은 측정에서 최종 상태, bbox, class와 Top-3 불일치는 0건이었습니다.
- confidence 최대 차이는 0.0085055232로 bit-exact parity 결과가 아닙니다.
- 평균과 p95 500ms 이하는 현재 N100 운영 진단 기준이며 설치 생성 조건이나 SLA로 사용하지 않습니다.
- 이 측정값은 장비 한 대의 진단 결과이며 지연시간 또는 SLA를 보장하지 않습니다.
- fallback 사용 여부는 /health/ready의 provider로 확인합니다. GPU 사용 시
  openvino+openvino_gpu, CPU fallback 시 openvino입니다.
- ERROR는 촬영 재시도 판정이 아니라 입력, 구성, 모델 또는 시스템 오류입니다.
- 설치 파일은 SHA-256 파일로 전송 중 손상을 확인할 수 있지만 현재 Authenticode 서명은 없습니다.
- Windows가 알 수 없는 게시자 경고를 표시할 수 있습니다. 전달받은 Setup EXE의 SHA-256을 먼저
  확인한 뒤 실행하십시오.

제거
- Windows 설정 > 앱 > 설치된 앱 > BIXOLON Scanner에서 제거합니다.
- 제거해도 작업자가 저장한 스캔 기록과 원본 이미지는 자동 삭제하지 않습니다.
- 기록은 현재 Windows 사용자 Application Support 아래 ProductScanner 폴더에 남습니다.
