BIXOLON Scanner 0.1.5 - N100 Hybrid Worker ZIP
================================================

실행 방법
1. ZIP 전체를 같은 폴더에 압축 해제합니다.
2. RUN-BIXOLON-WORKER.cmd를 실행합니다.
3. Worker 주소는 http://127.0.0.1:8000 이고 endpoint는 POST /v1/scan 입니다.
4. 종료하려면 Worker 창에서 Ctrl+C를 누릅니다.

실행 구성
- Detector: OpenVINOExecutionProvider CPU
- 주 Embedder, 180도 Embedder, 독립 Verifier: OpenVINOExecutionProvider Intel GPU
- Intel GPU graph 전체를 초기화할 수 없으면 경고 로그를 남기고 CPU Embedder로 재시작합니다.
- fallback 후 /health/ready의 provider는 openvino로 표시됩니다.
- Python, Flutter, CUDA는 별도로 설치하지 않습니다.
- 사용자별 version 디렉터리의 OpenVINO 컴파일 캐시를 사용합니다.

필수 조건
- Windows 10 1809 이상, x64
- Intel Processor N100과 활성화된 Intel UHD Graphics
- Intel Graphics Driver 32.0.101.6299 이상 권장
- Microsoft Visual C++ 2015-2022 x64 Runtime

무결성
- ZIP 옆의 .sha256 파일로 ZIP을 검증할 수 있습니다.
- worker-manifest.json에는 ZIP 내부 파일별 SHA-256이 기록됩니다.
- n100-reference-result.json은 이 구성을 선택할 때 사용한 N100 측정 원문입니다.

제한
- 이전 0.1.4+7 N100 참조 측정 100장에서 최종 상태, bbox, class와 Top-3는 CPU-only와
  같았습니다. 새 0.1.5 정책의 N100 성능 증빙은 아니며 대상 장비에서 다시 측정해야 합니다.
- confidence 최대 차이는 0.0085055232였으므로 bit-exact parity 결과가 아닙니다.
- 이 결과는 장비 한 대의 진단이며 SLA 또는 인증이 아닙니다.
- 배포 파일에는 Authenticode 서명이 없습니다.
