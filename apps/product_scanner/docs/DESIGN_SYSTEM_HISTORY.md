# 디자인 시스템 개선 이력

이 문서는 디자인 시스템의 누적 검수·개선 기록입니다. 현재 준수해야 할 계약은 [DESIGN_SYSTEM.md](../DESIGN_SYSTEM.md)를 따릅니다.
